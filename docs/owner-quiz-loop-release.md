# Owner quiz discovery and completion loop release

Approved for deployment by the developer on 19 October 2026. Base: `00592b7`.

The owner chat receives compact course-material catalogs with parent module titles,
turn-local snapshots and the existing 6,000-character read default. Missing-evidence
reads carry unsaved-job feedback and citations for subsequent preparation.

The native loop has no fixed total tool-call or reasoning-round count. A 90-second
turn deadline and factual non-progress checks bound execution. Completion checks
consider document/catalog continuation and can run again after new evidence.
Primary recovery uses automatic tool choice. Genuinely missing notes can produce
a clarification. Owner-only source access and exact Calendar approval remain.

The local advertised-function allowance is sixteen; eleven was verified through
IBM. No new search function, schema migration, provider change, keyword routing,
or frontend change is included in this release.

Combined synthetic real-IBM checks passed for spontaneous owner practice,
assessment-aligned practice, long documents, identical filenames under different
modules, missing notes, and nonowner PDF practice with resume/grading/isolation.
One PDF trial returned an IBM 500 before job creation; a separate trial passed.
The missing-notes check passed after correcting conflicting completion instructions.

Sandbox offline run: 486 tests, initially 472 passed, 12 skipped and two issues.
An obsolete forced-recovery assertion was updated and passed focused rechecks;
the Windows DPAPI synthetic test passed separately outside sandbox restrictions.
Fifteen Mini App delivery/native-completion checks and two clarification checks
passed after the final corrections. Historical experimental diagnostics and
prototype harnesses are not included in the production checkout. Syntax and
whitespace checks passed. Full-suite repetition was avoided after focused fixes.

Deployment requires only the Telegram bot to reload; the API and tunnel can remain
running. Existing startup maintenance and pending-update preservation remain as
implemented. No production record inspection or schema migration is part of rollout.

Owner acceptance remains: request a spontaneous quiz for the real course/week,
then open Generated Practice, complete it and review its explanations. Also check
an assessment-specific request and the working nonowner uploaded-material flow.
The real owner catalog/content and the original generic live preparation failure
have not been inspected by this release's synthetic tests.
